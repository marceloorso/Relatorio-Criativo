# Criação de Relatório Analítico

Este projeto visa a criação de um relatório analítico no Power BI com as seguintes características:

## Características do Relatório

- Cartões com informações como soma de venda, soma de descontos, etc.
- Definição das métricas do relatório na página inicial.

## Elementos da Primeira Página

1. **Objetos que definem o layout do relatório**
2. **Gráficos (visuais) e os campos que os compõem**
3. **Botões para navegabilidade**
4. **Segmentadores de dados**

## Segunda Página do Relatório

Na segunda página do relatório, foram adicionados os seguintes gráficos:

- **Gráfico de Radar**
- **Gráfico Waterfall**
- **Treemap**
- **Decomposition Tree**

## Publicação

Publicar o relatório no Power BI Service.

---

### Instruções Detalhadas

1. **Criação da Primeira Página**
    - Adicionar cartões para visualizar soma de venda, soma de descontos, etc.
    - Definir as métricas principais na página inicial.
    - Incluir objetos para o layout do relatório.
    - Criar gráficos e adicionar os campos relevantes.
    - Adicionar botões para facilitar a navegabilidade.
    - Incluir segmentadores de dados para filtragem eficiente.

2. **Criação da Segunda Página**
    - Adicionar os seguintes gráficos: Radar, Waterfall, Treemap e Decomposition Tree.

3. **Publicação no Power BI Service**
    - Publicar o relatório no Power BI Service para compartilhamento e análise.
